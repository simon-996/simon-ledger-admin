# AI 记账设计

日期：2026-09-29

## 目标与范围

在 Flutter 记账首页为已登录、获管理员授权的用户增加文字和语音 AI 记账。一次输入可以描述多笔流水；AI 只生成草稿，用户逐笔复核、修改、确认后才沿用现有记账保存流程。未确认草稿仅保存在本机，重启后可以继续。

第一期交付授权、文字解析、多笔草稿队列与复核；第二期在同一草稿流程前接入语音转写。AI 记账仅用于用户有记账权限的云端账本；本地账本、游客及只读成员继续使用原有手动记账。每次输入只针对当前选中的一本账本，不让模型决定或切换账本。此功能不创建新的账本角色、自动写入流水或修改既有手动记账能力。

## 架构与责任

- `simon-ledger-admin`：用户列表展示 AI 授权状态与开关；管理员的开启和撤销操作记录在现有后台审计体系中。后台不管理第三方密钥。
- `simon-ledger-api`：存储授权、检查账号和账本权限、限制调用量、调用 DeepSeek 解析文字和腾讯云转写语音、校验模型结果。AI 接口只返回草稿，不调用流水创建服务。
- `simon_ledger_flutter`：显示入口、录音或输入文字、展示可编辑的转写文本、逐笔复核与保存，并管理账号及账本隔离的本机草稿队列。AI 界面与队列逻辑独立于大型 `BookkeepingTab`，只通过小型适配层填充其现有字段、复用其保存路径。

供应商调用均由 A PI 服务端发起。DeepSeek 只处理文字解析；腾讯云“一句话识别”处理最长 60 秒的录音。两种输入最终进入同一套文字解析和草稿复核流程。语音转写与文字解析分别以服务端接口封装，替换供应商不改变 Flutter 草稿格式。

## 授权与后台

- 在 `user_account` 增加非空布尔字段 `ai_bookkeeping_enabled`，默认 `false`。新迁移位于现有 `006` 迁移之后；既有账号迁移后全部无权。彻底删除账号时字段随账号行物理删除，不保留独立的授权记录。
- 后台为单个普通账号设置授权，重复设置同一状态应安全且不重复产生状态变化。服务端通过现有管理员身份校验，并记录操作者、目标账号、旧值、新值和时间；审计中不含密钥或用户输入。
- 客户端查询当前账号与所选账本的 AI 可用状态，仅用于显示入口。每次转写、解析都重新校验：普通账号存在且状态正常、AI 开关已开启、账本未删除、当前用户是有创建流水权限的有效成员。撤销授权立即阻止新调用，客户端缓存不能充当授权依据。
- 撤销授权不删除已在本机生成的草稿；用户仍可按普通表单逐笔确认，但必须继续具备当前账本的原有记账权限。已知成员失效或账本不可用时禁止确认，草稿保留供用户查看、修改或主动放弃；离线期间尚未获知的权限变化由现有同步流程在服务端拒绝。

## 接口与数据契约

- `PUT /api/admin/users/{uuid}/ai-bookkeeping-access`：请求体仅含 `enabled`；服务端写入授权并记录审计。后台用户列表响应包含当前授权状态。
- `GET /api/ledgers/{ledgerUuid}/ai-bookkeeping/capability`：返回 `available` 和可展示的不可用原因，不返回供应商配置或额度明细。真正的权限判定仍发生在后续每次请求上。
- `POST /api/ledgers/{ledgerUuid}/ai-bookkeeping/parse`：输入为最多 1000 字的文字、客户端 IANA 时区及可选本地分类候选；限制请求频率。返回有序草稿数组及每条对应的原文片段、待确认字段和可展示提示。一次调用只解析所选账本，不执行写入。单次最多返回 10 笔；若输入超限或模型返回更多，不静默截断，而是提示用户拆分。
- `POST /api/ledgers/{ledgerUuid}/ai-bookkeeping/transcribe`：鉴权后接收最长 60 秒的 16 kHz 单声道 PCM 音频，要求转交腾讯云时 Base64 编码后的数据不超过其 3 MB 上限，并返回纯转写文本。服务端校验真实音频格式、大小与时长，不相信客户端声明。客户端允许用户修改文本后再调用 `parse`。客户端以短暂内存缓冲承载录音，不落盘。

解析草稿的字段包括收支类型、十进制金额字符串、币种、建议分类、备注、发生时间、付款人和参与人候选。DeepSeek 使用结构化输出，但其回复仍是不可信数据：API 验证 JSON、字段类型、金额范围、笔数、币种和时间；仅把人名按当前账本有效参与人做唯一匹配，模型不能直接指定人员 UUID。无匹配或重名时返回待选择状态。分类偏好目前保存在 Flutter 本机，不是 API 的权威账本数据：API 检查建议分类的格式与长度，Flutter 仅对本机现有分类精确匹配后预选，否则要求用户选择或明确新增。缺少必填字段不能自动补成看似确定的值。可解析部分保留为草稿，用户补齐后才能确认。

## Flutter 交互与本机草稿

1. 有权限且当前选中可记账的云端账本时显示“AI 记账”入口；手动记账始终可用。首次使用告知用户文字会发送至 DeepSeek、录音会发送至腾讯云进行处理，并说明本机草稿会保留至确认或主动放弃。
2. 用户输入文字，或录音后先核对转写文本。解析产生按原文顺序排列的草稿队列；每张卡片显示“第 N/M 笔”、原文片段、可编辑字段与待补齐提示。
3. 用户逐笔确认、跳过或返回修改。确认一笔才调用现有 `transactionProvider.addTransaction` 路径；已成功保存的流水立即生效，后一笔失败不回滚前一笔，也不自动重试。每笔在本机预先分配稳定的草稿及操作标识，复用现有 `clientOperationId` 幂等机制；应用在“保存成功但队列尚未标记完成”时崩溃，恢复时先核对本地已保存流水，避免重复提交。
4. 未确认队列存入按普通账号 UUID 和账本 UUID 隔离的本机持久存储，不与现有单笔 `BookkeepingDraftPreference` 混用。重启、切换页面或重新登录同一账号后提示继续；切换账号看不到他人的草稿。已确认或主动跳过的条目从队列移除，其余一直保留至用户处理或放弃。退出队列前说明已确认与未确认数量。
5. 恢复时对照本机当前账号与账本投影重新检查有效参与人、币种和本机分类；联网刷新后再次检查。已失效的选择取消预选并提示修改，不凭过期草稿直接保存。授权撤销后不再提供转写或重新解析，但可按手动记账流程处理旧草稿。原始录音不进入草稿队列，转写成功或失败后均清除客户端内存音频缓冲；失败时提示重新录制。

## 密钥、隐私与成本控制

- DeepSeek 和腾讯云 API Key 仅由 API 服务端从部署环境的密钥配置读取；不得写入源码、Git、Flutter 包、后台页面、数据库授权记录或日志。仓库只允许无真实值的配置示例。密钥缺失时对应 AI 能力关闭并给出可理解的错误，不回退为客户端直连。密钥可在服务商侧轮换，无需改代码。
- 服务端不持久化原始录音、原始输入或模型完整响应，不在普通日志、错误日志或审计日志中打印它们；记录匿名化的调用次数、时长、耗时和错误类别即可。第三方对请求的处理与留存由其服务条款决定，首次使用说明需如实告知。发送给 DeepSeek 的上下文限定为用户本次输入、所选账本必要的币种与分类候选；不发送历史流水、完整账本资料或其他成员账号信息。
- 服务端设置可配置的单用户和全局调用限额、音频大小及时长限制、超时和并发限制。超限、第三方不可用或 JSON 无效时不生成假草稿，保留用户输入并可回到手动记账。DeepSeek 解析按整段输入调用一次，不按生成的每张卡片重复计费。语音和文字调用量分别监控。

## 验收与测试

- 新老账号默认无授权；后台开启后可用，撤销后新请求立即拒绝；无权访问的本地账本、游客、只读成员、已删除或禁用账号无法调用 AI，手动记账不受影响。
- 一段文字可返回多笔独立草稿，顺序正确；错误金额、含糊人名、未知参与人、不存在的分类和模型格式错误均不能悄悄生成可直接提交的流水。
- 每笔确认只保存一次；跳过不保存；中途失败不影响此前已确认流水；关闭应用或崩溃后恢复未确认队列且不重复保存。账号切换、账本或人员变化不会泄漏或错误复用草稿。
- 语音上传必须经过授权，PCM 格式、时长及腾讯云编码后 3 MB 大小限制生效；用户可改转写文本；转写失败提示重新录制，不产生空流水；内存录音缓冲在成功、失败或放弃后均清除。
- 使用伪造的 DeepSeek 与腾讯云客户端进行 API 单元和集成测试，覆盖超时、限流、异常响应及密钥缺失；Flutter 使用伪造 API 测试入口、逐笔复核和本机恢复。生产密钥不参与自动化测试，也不写进测试快照。

## 交付顺序

先完成 API 授权迁移及后台开关，再完成 DeepSeek 文字解析与 Flutter 多笔草稿复核，最后接腾讯云语音转写。每一阶段保持原有手动记账可用。上线前先执行新增数据库迁移并配置服务端密钥及限额；未配置供应商密钥时 AI 功能保持关闭。
